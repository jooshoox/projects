# Coding Projects

This repository contains various coding projects and utilities.

## File Organizer
A Python script that organizes files in a directory based on their extensions. The script automatically categorizes files into appropriate folders like Documents, Images, Audio, Video, etc.

### Features:
- Automatically creates category subdirectories
- Handles file naming conflicts
- Provides detailed logging
- Supports various file types
- Command-line interface with optional verbose mode
